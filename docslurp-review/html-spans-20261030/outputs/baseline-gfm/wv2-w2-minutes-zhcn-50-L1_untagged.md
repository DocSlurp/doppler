### （一）2026 年第三季度报告

财务总监王丽娟汇报了第三季度经营情况：第三季度实现营业收入 24,870 万元，环比增长 10.8%；前三季度累计营业收入 65,300 万元，同比增长 14.2%。来自新能源客户的收入占比提升至 47.6%。应收账款余额较年初增加较多，主要集中在两家整车企业。

### 图 1 近五个季度营业收入

独立董事李明哲提出，应收账款周转天数已由 62 天增加至 78 天，建议管理层制定专项清收方案并在下次会议上报告。董事马骏建议在季度报告中补充说明主要客户集中度风险。经审议，会议通过该议案。表决结果：同意 7 票，反对 0 票，弃权 0 票（应参加表决董事 7 名）。### （二）投资建设二期年产 3 万吨电池级导电浆料项目

总经理吴卫东介绍了项目可行性研究报告：项目选址于公司嘉兴生产基地，总投资约 4.86 亿元，其中设备投资 3.12 亿元，建设期 18 个月，预计达产后年均新增营业收入 9.6 亿元，税后内部收益率 15.3%，静态投资回收期 6.2 年（含建设期）。董事郑佳关注碳纳米管原材料价格波动对项目收益的影响，要求补充敏感性分析。独立董事 Margaret Lin 林美华认为项目与公司战略一致，但建议分两阶段投入设备，以降低下游需求不及预期的风险。董事许文清对项目的资金来源提出疑问，财务总监答复拟以自有资金约 1.5 亿元和银行项目贷款约 3.36 亿元解决。经审议，会议同意该项目分两阶段实施，并授权管理层办理立项、环评及土地等相关手续。表决结果：同意 6 票，反对 0 票，弃权 1 票（应参加表决董事 7 名）。董事许文清投弃权票，理由是希望在银行授信落实后再作决定。

### （三）向银行申请综合授信额度

为满足生产经营和项目建设的资金需求，公司拟向中国工商银行、招商银行等金融机构申请合计不超过人民币 8 亿元的综合授信额度，期限一年，授信品种包括流动资金贷款、项目贷款、银行承兑汇票等。经审议，会议通过该议案，该议案尚需提交股东大会审议。表决结果：同意 7 票，反对 0 票，弃权 0 票（应参加表决董事 7 名）。

董事会秘书提示根据《公司章程》第一百一十条，对外投资金额超过最近一期经审计净资产 10%的事项，应当在董事会审议通过后提交股东大会审议。### （四）安全生产和质量体系情况汇报

吴卫东总经理汇报：前三季度未发生一般及以上生产安全事故；嘉兴基地完成了危险化学品仓库的智能监控改造。IATF 16949 监督审核中发现一般不符合项 3 项，已制定整改计划。董事会要求安全生产责任制修订后组织全员考核。
