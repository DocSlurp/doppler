感谢您选用浩川仪器 TH-30 系列温湿度记录仪。本手册介绍产品的安装、配置、使用、维护与故障排除方法。使用前请仔细阅读本手册，并妥善保管以备查阅。由于产品持续改进，本手册内容如有变更，恕不另行通知；最新版本请访问 www.haochuan-inst.example 下载。## 安全注意事项

警告请勿将记录仪靠近火源或加热至 85 ℃ 以上，锂电池过热可能导致起火或爆炸。请勿对电池进行充电、拆解或短路。

警告在易燃易爆环境中使用前，请确认所选型号具有相应的防爆认证。标准型 TH-30 不适用于危险场所。

注意用于药品冷链（GSP）验证时，请确保记录仪在校准有效期内，并在使用前完成时间同步。

# 1 产品概述

TH-30 是一款高精度、低功耗的温湿度记录仪，适用于医药冷链、仓储物流、实验室、档案馆和数据中心等场景。设备采用瑞士进口数字温湿度传感器，可通过 USB、RS-485、Wi-Fi 或 4G 将数据上传至浩川云平台或用户自建的服务器，支持超限报警和数据防篡改（SHA-256 签名）。

- 高精度：温度 ±0.2 ℃，湿度 ±1.5 %RH，每台设备出厂均附校准证书

- 长续航：标准配置下电池可使用约 18 个月

- 大容量：本地存储 50 万组数据，断网期间数据不丢失，恢复联网后自动补传

- 合规：满足 GSP 附录《温湿度自动监测》和 21 CFR Part 11 的数据完整性要求

# 4 安装

- 1. 拆除电池绝缘片

- a) 打开背面电池仓盖（十字螺丝刀）。

- b) 取出透明绝缘片，屏幕显示开机画面后合上仓盖。

- 2. 选择安装位置

- a) 避免阳光直射、出风口和热源附近。

- b) 冷库内距离门口至少 1.5 m，高度建议 1.2 ～ 1.8 m。

- 3. 固定设备

- a) 用 2 颗 M4 螺丝将支架固定在墙面。

- b) 将主机向下滑入支架卡槽，听到“咔哒”声即安装到位。

安装完成后，请等待约 15 分钟，使设备与环境达到热平衡后再开始正式记录。冷库等低温环境中，从常温移入时应等待 30 分钟以上，以免传感器凝露。使用外置探头时，请将探头线缆固定在支架上，探头头部应悬空放置，不得贴靠墙面或货物。

## 4.1 冷链运输中的使用

用于冷藏车运输时，请将记录仪固定在货物中部，避免靠近蒸发器出风口。启运前可设置“延时启动”，到达后通过 USB 直接生成 PDF 报告。# 按键与显示

- 功能键（短按）：切换显示温度、湿度、最大值/最小值

- 功能键（长按 3 秒）：开始或停止记录

- 设置键（长按 5 秒）：进入配网模式，Wi-Fi 指示灯快闪

- 屏幕右上角图标：电池电量、信号强度、报警状态

# 6 参数配置

通过 USB 连接电脑后，设备在电脑上显示为虚拟串口（波特率 115200，8N1）。可使用 HC- Config 软件或任意串口终端发送 AT 指令进行配置：

代码 1 串口 AT 指令示例

AT+INTERVAL=300 // 记录间隔 300 秒 AT+ALARM=T,2.0,8.0 // 温度报警上下限 2.0 ℃ ～ 8.0 ℃ AT+ALARM=H,35,75 // 湿度报警上下限 35 %RH ～ 75 %RH AT+MODE=LOOP // 循环记录 AT+WIFI="Cold-Store-2F","********"

AT+SAVE OK

也可以将配置写入 JSON 文件，通过 HC-Config 批量下发到多台设备：

代码 2 设备配置文件 config.json

{

"device": "TH-30W", "interval_s": 300, "alarm": {"temp": [2.0, 8.0], "humi": [35, 75], "delay_s": 600}, "mqtt": { "host": "mqtt.haochuan-inst.example", "port": 8883, "topic": "coldchain/warehouse-2/{sn}", "tls": true }, "timezone": "Asia/Shanghai"

}

提示报警延时（delay_s）用于避免开门取货时的短时超限误报。用于 GSP 验证时，请按照企业质量管理文件设置，不宜超过 15 分钟。

## 6.2 报警通知

记录的数据可以通过 HC-Config 导出为 PDF 报告或 CSV 文件。PDF 报告包含设备序列号、校准信息、统计值和曲线图，并带有数字签名，可直接用于药品质量追溯。

## 7.1 Modbus RTU

RS-485 接口默认地址为 1，波特率 9600，8N1。保持寄存器 0x0000 为温度（有符号整数，单位

- 0.01 ℃），0x0001 为湿度（单位 0.01 %RH）。以下 Python 示例每 10 秒读取一次数据：

代码 3 读取实时数据

import time import minimalmodbus

logger = minimalmodbus.Instrument("/dev/ttyUSB0", 1) logger.serial.baudrate = 9600

while True: t = logger.read_register(0x0000, 2, signed=True) h = logger.read_register(0x0001, 2)

print(f"温度 {t:.2f} ℃ 湿度 {h:.2f} %RH") time.sleep(10)
