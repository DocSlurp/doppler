Five valid runs; aggregate user + system CPU. Markdown adds six sample-page interpretations and finds no tables. This does not establish equivalent quality, fastest export, or parallel wall-time scaling.

Largest measured trap: enabling image callbacks on eight scanned pages increased CPU from 0.018 s to 2.353 s. JPX image parameter discovery decodes pixels before the callback. A predecode metadata path deserves priority.

Five alternatives retained, with disagreements
  • Architect: evidence / layout / asset boundaries; scoped tag ownership still needs fixes.
  • Minimalist: reuse TextOutputDev; placeholders alone fall short of preservation.
  • Performance: bounded native projection; current Markdown quality is poor.
  • Fidelity: topology and HTML/SVG; real borderless extraction and math remain unproven.
  • Radical: region-adaptive parts bundle; event capture is not faithful rendering replay.

Implementation order: fix marked-content ownership → collect reusable evidence → ship linked prose, tables and complete assets → add composed figures, robust reading order and bounded workers.
